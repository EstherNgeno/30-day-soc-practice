# 30-Day SOC Practice

A 30-day hands-on practice log for Security Operations Center (SOC) skills, built in my home security lab.

## Goals

- Build daily habits around log analysis, alert triage and incident investigation
- Practice with common SOC tools and techniques
- Document each day's work, findings and lessons learned

## Structure

Each day's notes and artifacts will live in their own folder (for example `day-01/`, `day-02/`, ...).
